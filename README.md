# Generative and Classification Study on Imagenette and Imagewoof

This repository explores generative models and their impact on image classification tasks using two subsets of ImageNet: **Imagenette** and **Imagewoof**. All experiments and analyses are implemented in a structured Jupyter notebook, named Proyect.ipynb

---

## Overview

We focus on three key experiments:

### 1. Training a DCGAN

We start by training a **Deep Convolutional Generative Adversarial Network (DCGAN)**. This architecture follows the official PyTorch implementation, allowing us to generate synthetic images from scratch separately for Imagenette and Imagewoof datasets.

### 2. Classification on Real Images

We then train and evaluate five different classifiers using only real images from each subset. The goal here is to establish baseline performance and benchmark classifier capabilities without synthetic data interference.

### 3. Leveraging Pretrained BigGAN for Synthetic Data

Finally, we select the best pretrained **BigGAN** model based on the **Frechet Inception Distance (FID)** metric, separately evaluated for Imagenette and Imagewoof subsets. Using the generated images from the chosen BigGAN model, we retrain our classifiers. This step helps us assess how effectively synthetic data, generated by high-quality GANs, improves the classifiers' ability to generalize to unseen real images.

---

## Structure

- `DCGAN Implementation`: Training and evaluating GAN-generated images.
- `Classifier Training`: Benchmarking classifiers with real data.
- `Synthetic Data Experiment`: Retraining classifiers with BigGAN-generated synthetic data and evaluating improvements.
